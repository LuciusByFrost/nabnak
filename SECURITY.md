# Security policy

Security fixes target the current default branch. See [the audit and architecture](docs/SECURITY.md) for scope, safeguards and hosting limits.

Please report vulnerabilities through [GitHub private vulnerability reporting](https://github.com/LuciusByFrost/nabnak/security/advisories/new) when enabled. If unavailable, ask the maintainer to enable it without publishing exploit details or private user data in an issue. Include the affected revision, browser, minimal synthetic reproduction, impact and suggested mitigation. Never attach personal recovery files, credentials or real user data.

NABNAK stores plaintext data locally. It has no server, accounts or encryption service. Do not use it to store passwords, access tokens or sensitive credentials. Back up important work before changing browser storage or restoring a recovery file.
